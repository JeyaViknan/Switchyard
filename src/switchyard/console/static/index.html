      How to connect real providers

      Nothing here is hard-wired to the synthetic fleet. Point a provider at a real OpenAI-compatible endpoint and the same image, pipeline and dashboards keep working — the banner above switches to LIVE PROVIDERS on its own, because it is derived from configuration rather than a flag.

      Then set CONSOLE_DEMO_CONTROLS=false so this console serves read-only. Full notes in docs/production.md.
