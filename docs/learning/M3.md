# M3 — The live map

## What was built
Four static files — shell, stylesheet, app module, map module — served under a
strict CSP with no build step. Hash-routed pages for the map, tenants,
providers, guided demos, system and API. One `EventSource` feeds everything.

## Why
The map draws `max_concurrency` as individual slots, outlined per tenant where
a reserved floor owns them and dashed where they are shared. A utilisation bar
says "58%"; the grid says *whose* 58% — which is the whole argument for floors.
Particles move at measured rates, and the legend says a dot is a rate and not a
request, because at 25 rps the honest version is unreadable.

## Interview questions

**Why no framework?** For four files it would add a toolchain to install, pin
and audit, and put a build step between the source and what runs. It also let
the CSP stay `default-src 'self'` with no `unsafe-inline`, which a test
enforces — inline styles fail silently otherwise.

**What did running it find that tests had not?** Three bugs that live between
a correct browser and a correct server: the SSE stream was opened before the
login cookie existed and kept reporting "not signed in", so signing in undid
itself a second later; the control buttons were rebuilt every second so clicks
landed on replaced nodes; and two text lines that fit at 420px overlapped at
the 236px width that actually ships.

**Your demo showed a red X. Why is that good?** Because the verdicts are
measured, not scripted. That one turned out to be a scoring bug — the check
said FAIL when it meant "nothing was refused, so there is no evidence" — and
it now reports pending with what to change. A demo that cannot fail is an
animation.

**How do you keep the console from hurting what it measures?** 30fps ceiling,
rendering paused when the tab is hidden, buttons rebuilt only on change, and a
traffic generator capped at 30 rps and 120 streams. It shares a CPU with the
gateway.

**Accessibility?** Status is never colour alone — every breaker state carries
an icon and a word. Light and dark via CSS variables, reduced motion drops the
particles and loses no information, and the layout is mobile-first because the
demo happens on a phone.
